# Help system

Relmote should explain itself from the command line.

## Two forms of help

`relmote --help`

- concise command/argument reference;
- generated by the CLI parser;
- useful for experienced users and scripting.

`relmote help`

- plain-language onboarding;
- explains common workflows;
- emphasizes what commands mean rather than parser syntax.

## Topic help

Examples:

```text
relmote help support
relmote help check
relmote help remote
relmote help workspace
relmote help update
relmote help privacy
```

## Future

Potential contextual help:

```text
relmote help tailscale
relmote help ssh
relmote help permissions
relmote help troubleshooting
```

The TUI and web UI should link to the same conceptual help content where practical.

## Principle

> A user should not need the GitHub repository open just to understand how to use Relmote.
