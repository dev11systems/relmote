# Preview UX checklist

A preview is not ready merely because the backend works.

## Installation

- [ ] one obvious download for the target OS
- [ ] no Python/Git required for ordinary tester
- [ ] no editing config files
- [ ] no firewall/port knowledge required for common path
- [ ] clear uninstall/quit behavior

## First run

- [ ] identify this computer in plain language
- [ ] explain whether support is currently off/on
- [ ] one primary next action
- [ ] advanced networking hidden by default
- [ ] no account required

## Receiving support

- [ ] Enable/Get Help button
- [ ] helper identity shown
- [ ] permissions summarized in ordinary language
- [ ] obvious Allow/Deny
- [ ] obvious Stop Support
- [ ] re-enable later without reinstalling

## Diagnostics

- [ ] findings shown before raw JSON
- [ ] observed/tested/inferred/unknown are understandable
- [ ] technical evidence expandable
- [ ] errors suggest a next step

## Remote access

- [ ] preferred private path selected automatically when possible
- [ ] user does not type IP/port in common path
- [ ] connection security summarized simply
- [ ] technical path available under Details

## Workspace / agent support

- [ ] project shown by friendly name
- [ ] file changes displayed as reviewable diffs
- [ ] writes require clear approval by default
- [ ] tests/tools described by effect, not assumed harmless
- [ ] project boundary understandable
- [ ] Stop/revoke works immediately

## Exit

- [ ] session can be revoked
- [ ] support availability can be disabled
- [ ] temporary mode leaves no background service
- [ ] persistent mode is clearly labeled
