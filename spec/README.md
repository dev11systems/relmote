# Relmote specifications

This directory contains draft/open specifications that are intended to outlive any single Dev11 hardware implementation.

- [Constrained envelope v0.1](constrained-envelope-v0.1.md)

## Specification philosophy

Relmote specifications should be:

- publicly readable;
- implementable without Dev11 permission;
- testable locally;
- versioned;
- conservative about breaking changes;
- explicit about provisional versus normative sections.

Reference hardware may implement these specifications, but reference hardware does not define compatibility by itself.
