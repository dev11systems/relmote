# Relmote reference modules

These are **reference module concepts**, not announced products.

Each module should eventually include:

- use cases;
- capabilities;
- power envelope;
- physical class;
- trust considerations;
- repairability;
- descriptor example;
- prototype plan.

## Initial module families

- [Mesh](mesh.md)
- [Serial / Console](serial-console.md)
- [KVM](kvm.md)
- [Ethernet / PoE](ethernet-poe.md)
- [Cellular](cellular.md)
- [Battery](battery.md)
- [Embedded Debug](embedded-debug.md)

Community modules are expected and encouraged.
