# Relmote hardware concepts

These are reference forms, not product tiers.

- [Mini](mini.md) — minimal MCU-class Relmote.
- [Pocket](pocket.md) — phone-sized everyday-carry Relmote.
- [All-in-One](all-in-one.md) — power-bank-sized integrated field Relmote.

All should share the same protocol, authorization model, capability discovery, and open compatibility philosophy.

A DIY device does not need to match any of these forms to be Relmote-compatible.
